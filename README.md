# BestShot Travel Photo Lab

BestShot 是一个本地运行、隐私优先的旅行照片整理与多人合照融合工具。智能整理可以批量导入 2–200 张照片，将相似场景归组，并在每组内按质量从高到低排序；照片合成则允许从另一张连拍照中融合更好的局部内容。

> 默认整理完全在本地完成。只有用户主动点击“生成九图”时，通过动态质量门槛的分组最佳 JPEG 缩略图才会发送到用户自己配置的视觉 API；原图、组内其他照片和 API Key 不会由前端上传或保存。

## 当前功能

- JPG / JPEG / PNG / WebP / HEIC / HEIF 批量混合导入（最多 200 张）
- 兼容 iPhone 导出的 MPO 容器 JPEG，并支持长边 12000 像素以内的高分辨率整理
- 分析前可逐张移除已选择的照片，或一键清空本次选择
- 结合感知哈希、画面结构、颜色直方图和 EXIF 拍摄时间的相似照片分组
- 保守 / 标准 / 宽松三档分组灵敏度，使用组内最低相似度约束防止链式误合并
- 按清晰度、曝光、色彩、构图和画面简洁度生成可解释质量评分；组内和分组列表都按各自最高分降序排列
- 每组自动标记综合质量最高的照片
- 左侧分组列表独立滚动，中间照片浏览区域保持不动
- 可从达到质量门槛的分组最佳缩略图中生成朋友圈九图、顺序、理由和配文建议
- 先整体观察候选场景形成故事线与布局方案，再按方案选片，最后从完整九宫格视角复核相邻相似度、色彩节奏和整体美感
- 生成后的朋友圈文案位于标题下方、九图上方，可一键复制
- 九图中的任意一格都可以手动选择尚未使用的新分组及具体照片，也可以让视觉模型结合相邻画面自动换组
- 最终九张原图可按顺序打包下载为 ZIP
- 生成前可选填主题、地点、故事心情和文案风格；提交过的内容会保存在当前浏览器中供下次复用

- JPG / PNG 双图上传，自动修正 EXIF 方向
- SIFT + RANSAC 全局配准与质量门槛
- 原图坐标系的自由画笔、橡皮擦、笔迹撤销/重做
- 稀疏光流 + 局部仿射对齐；失败时安全回退到全局结果
- 羽化、Poisson 标准克隆和混合梯度三种融合方式
- 合成前后拖动对比、最近 10 个编辑版本、高清 PNG 导出
- 照片和任务数据仅保存在 `.bestshot-data/`，默认服务只监听 `127.0.0.1`

## Windows 一键启动（推荐）

直接双击项目根目录中的：

- `启动 BestShot.bat`：启动服务并自动打开浏览器。
- `停止 BestShot.bat`：使用完毕后停止后台服务。

需要预先安装 Python 3.11+ 和 Node.js 20+。首次启动会自动准备依赖，可能需要等待几分钟；之后通常数秒即可打开。无需打开 PowerShell，也无需输入命令。

如果程序已经启动，再次双击启动器只会重新打开浏览器，不会重复启动服务。

## 配置 DeepSeek 朋友圈精选

1. 将项目根目录的 `.env.example` 复制为 `.env`。
2. 在 `.env` 中填写 `DEEPSEEK_API_KEY`。
3. 重启 BestShot；分类完成后点击“生成九图”。

API Key 只由本地后端读取，不会写入前端代码。只有用户主动点击精选按钮时，每个分组的最佳 JPEG 缩略图才会发送到 DeepSeek；原始照片不会因此上传。

## 智能整理的评分边界

当前本地评分由清晰度 16%、曝光 18%、色彩 13%、构图 23% 和画面简洁度 30% 组成。简洁度会惩罚过密边缘和均匀散布的复杂纹理，同时也会校正“杂物很多导致拉普拉斯清晰度虚高”的问题。它适合优先排除模糊、严重过暗/过曝或明显杂乱的照片，但尚未可靠判断人物是否闭眼、表情是否自然，也不了解个人审美偏好。

视觉模型仅在用户主动生成朋友圈九图时介入：系统先从每个分组的本地第一名中按动态质量门槛筛出候选，并连同可选背景信息生成故事与布局方案；随后再次观察同一批候选，按方案选择和排列九张照片。它不会在分类时自动上传全部照片或组内其他照片。

分组采用本地轻量视觉特征，首版重点识别连拍、相近构图和同一场景。若未来需要处理视角变化很大的同一景点，可以在 `photo_classifier.py` 的特征层接入 DINOv2，同时保持 API 与前端不变。

## 合成功能使用边界

V1 适合相机位置、构图和人物姿态变化不大的连续合照。大幅转头、身体严重遮挡、人物位置互换或完全不同视角，传统计算机视觉无法保证可靠结果。自动局部对齐不会强行扭曲人脸；质量不足时会回退并显示提示。
